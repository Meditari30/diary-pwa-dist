# Diary PWA Dist

一个可离线使用的日历日记本 PWA 静态发布包。

## 功能

- 按日历查看和编辑每天的日记
- 支持提前记录明天的日记
- 自动保存到浏览器本地存储
- 支持 PWA 安装和基础离线缓存

## 本地预览

需要先安装 Node.js，然后在项目目录运行：

```bash
node serve.mjs 4174
```

打开浏览器访问：

```text
http://localhost:4174/
```

Windows 用户也可以双击 `启动游戏.bat` 启动本地预览。

## 发布

这是已经构建好的静态文件目录，可直接部署到 GitHub Pages 或任意静态网站托管服务。
